PyWaveletsのCWTで端点の影響を調べる：スケール・周波数・境界条件

連続ウェーブレット変換の端点付近で係数が変わる仕組みを解説。PyWaveletsでスケールをHzに換算し、ゼロ・反射・周期パディングによる影響範囲を既知の連続信号と比較します。

November 22, 2026 Updated November 22, 2026 5 min read
信号処理 Python

記録の冒頭だけ、CWTのスカログラムで低周波の帯が弱い。この結果には、実際に低周波成分が弱まった場合と、変換に必要な冒頭より前の信号が観測されていない場合があります。PyWaveletsでこの境界効果を再現し、どの範囲まで延長の仮定に左右されるかをスケールごとに測ります。変換とスカログラムの基礎は ウェーブレット変換入門 を参照してください。

スケールをHzに換算する

CWTは、ウェーブレットを時間方向にずらしながら信号と照らし合わせます。スケールを大きくするとウェーブレットが時間方向に伸びるので、対応する周波数は低くなります。スケール \(s\) に対応する周波数 \(f(s)\) は、サンプリング周期を \(Delta t\) 秒とすると以下のように求められます。

\[ f(s)=\frac{\operatorname{scale2frequency}(\mathrm{wavelet},s)}{\Delta t}\quad\mathrm{Hz} \]

たとえば、複素Morletウェーブレット cmor1.5-1.0 を使い、256 Hzで標本化した場合、スケール8は32 Hz、スケール64は4 Hzに対応します。これはウェーブレットの代表周波数で、各係数は周辺の周波数にも応答します。

pywt.cwt(x, scales, wavelet, sampling_period=1 / fs) の第2戻り値も同じ換算値です。入力データとスケールが同じなら、この引数で変わるのは返される周波数で、係数は同じです。別の標本化周波数で同じHzを狙うなら、pywt.frequency2scale(wavelet, target_hz / fs) でスケールも求め直します。小さいスケールでは離散化したウェーブレットにエイリアシングが起きるため、高周波側の範囲はフィルタの応答も確認して決めます。 PyWaveletsのCWTドキュメント

観測区間の外側をどう扱うか

記録の先頭から20サンプルの位置で係数を求めるとき、ウェーブレットの波形がそこから左に20サンプルより長く伸びれば、積分に使う信号の一部は記録の外側にあります。同じ位置でも、大きいスケールほどこの影響を受けやすくなります。

延長方法外側に置く値妥当な状況
ゼロ両端の外側を0で埋める孤立したパルスなど、記録の前後で信号がほぼ0とわかる
反射端の標本を重複させず、内側の値を鏡像として並べる端の前後が鏡像に近いと考えられる
周期記録の末尾を先頭側から参照し、先頭を末尾側で繰り返す記録全体に整数周期が入り、周期的な連続性が期待できる
追加観測実際に記録した前後の値を使う元の長い記録から関心区間を切り出す場合

端点の係数は、選んだ延長方法の下での推定値です。観測した区間が同じでも、信号がそのまま続いた場合と、記録の外で0だった場合では参照係数が変わります。

1%を超える差がどこまで及ぶか

人工信号なら、記録の外も含めた余弦波を先に作れます。サンプリング周波数は256 Hzとし、その中央の501サンプルだけを観測したとします。501という区間長を選ぶと、ここで試す周期8、16、32、64サンプルのいずれについても、観測区間が整数周期になりません。wrap で区間をそのまま繰り返すと、参照信号とは異なる前後が作られます。

各行では波形の周波数をウェーブレットの代表周波数に合わせます。長い余弦波にCWTを適用した結果を参照とし、同じ501サンプルに3種の延長を施した結果を比較します。複素係数の差の絶対値を参照係数の大きさの中央値で割り、1%を超える点のうち、最寄りの端から最も遠い位置を求めます。表の幅は、端のサンプルを1として数えた、左右の大きい方です。

NumPyとPyWaveletsをインストールして実行できます。

python -m pip install numpy PyWavelets

import numpy as np
import pywt

fs = 256
length = 501
pad = 1024
scales = np.array([8, 16, 32, 64])
wavelet = "cmor1.5-1.0"
frequencies = pywt.scale2frequency(wavelet, scales) * fs

n = np.arange(-pad, length + pad)
observed = slice(pad, pad + length)
sample = np.arange(length)
edge_distance = np.minimum(sample, length - 1 - sample)

def coefficients(signal, scale):
    values, _ = pywt.cwt(
        signal, [scale], wavelet, sampling_period=1 / fs, method="conv"
    )
    return values[0, observed]

def affected_width(estimate, reference):
    relative_error = np.abs(estimate - reference) / np.median(np.abs(reference))
    affected = edge_distance[relative_error > 0.01]
    return int(np.max(affected + 1, initial=0))

print("scale    Hz   zero  reflect  wrap")
for scale, hz in zip(scales, frequencies):
    full_signal = np.cos(2 * np.pi * hz * n / fs + 0.2)
    segment = full_signal[observed]
    reference = coefficients(full_signal, scale)
    widths = [
        affected_width(coefficients(np.pad(segment, pad, mode=mode), scale), reference)
        for mode in ("constant", "reflect", "wrap")
    ]
    print(f"{scale:5d} {hz:5.1f} {widths[0]:6d} {widths[1]:8d} {widths[2]:5d}")

ゼロ延長の差が現れる幅は、32 Hzで端から17サンプル（約66 ms）、4 Hzで133サンプル（約520 ms）でした。反射は32 Hzでこの幅を縮めますが、16 Hz、8 Hz、4 Hzではゼロより幅が広がっています。また、周期延長の幅が4 Hzでゼロ延長と同じでも、係数の差そのものが等しいとは限りません。表はこの信号・比較方法での距離を示しており、係数の誤差全体を順位づけする指標ではありません。

スカログラムで端に現れた成分を判断する

端の観測不足が影響する領域は周波数によって幅が異なります。CWTの図では、境界効果を考慮するために**影響円錐（cone of influence, COI）**を使うことがあります。TorrenceとCompoの定義では、端点の不連続によるウェーブレットパワーが \(e^{-2}\) に減衰する時間を境界の目安とします。今回の幅は複素係数と既知の参照との差を1%で判定しています。COIを描く場合は使用するウェーブレットと定義を明記し、今回の値と区別します。 Torrence and Compo, A Practical Guide to Wavelet Analysis

  1. 長い記録がある場合は、前後を含めてCWTを計算し、関心区間の係数を切り出す。
  2. 前後を観測できない場合は、対象に合う複数の延長を試し、確認したい周波数・時刻で係数やピークの位置が変わるかを比べる。
  3. 図に境界の目安を描く場合は、周波数ごとに幅を変え、延長方法や判定基準を添える。端点付近のイベントを解釈するとき、延長によって結論が変わる範囲を判断できる。

よくある質問

CWTのスケールをHzに換算するには？

pywt.scale2frequency(wavelet, scales) にサンプリング周波数を掛けます。pywt.cwt にサンプリング周期を指定すれば、第2戻り値で対応する周波数を取得できます。

なぜ低周波ほど境界の影響を受ける範囲が広いのですか？

同じウェーブレットでは低周波側ほどスケールが大きく、係数の計算に使う波形が時間方向に広がります。そのため、端から離れた時刻でも波形の一部が観測区間の外にかかります。

反射パディングを使えば端点付近の係数を信頼できますか？

反射は、端の外側が内側の鏡像に近い場合に有効です。実データでは、観測できる区間を広げるか、複数の妥当な延長方法を比較して、係数や結論が境界条件にどれだけ依存するかを確認します。
