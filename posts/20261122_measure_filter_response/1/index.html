入力と出力のログからフィルタの周波数応答を測る：SciPyのH1推定とコヒーレンス

scipy.signal.csdとwelchで入力・出力ログからH1周波数応答を推定します。引数の順序で位相の符号が変わる理由、コヒーレンスと入力PSDで使える帯域を選ぶ方法、設計値との比較をPythonで解説します。

November 22, 2026 Updated November 22, 2026 5 min read
信号処理 Python

同じ時刻に記録した入力 x と出力 y があれば、フィルタの係数が分からなくても、ログから周波数ごとのゲインと位相を推定できます。ただし、入力に十分なエネルギーがない周波数や、出力で測定ノイズが支配的な周波数では、比を計算できても応答として採用できません。

ここでは、SciPyの csd と welch でH1推定値とコヒーレンスを計算し、理論値が分かっているローパスフィルタと比較します。

H1推定で入力を先に渡す理由

入力・出力を同じ位置で区切り、窓を掛けた区間FFTを \(X_k\) 、\(Y_k\) とします。SciPyの csd(x, y) は \(X_k^*Y_k\) を区間間で平均します。Welch法による入力PSDは \(|X_k|^2\) の平均です。スケーリングと窓の設定を揃えれば、H1推定値は次の比になります。

\[ \widehat H_1(f)=\frac{P_{xy}(f)}{P_{xx}(f)},\qquad \gamma^2_{xy}(f)=\frac{|P_{xy}(f)|^2}{P_{xx}(f)P_{yy}(f)} \]

対象が測定中に変わらない線形時不変系で、出力が \(Y=HX+N\) と書けるとします。出力ノイズ \(N\) が入力と相関しなければ、\(X^*N\) の期待値はゼロです。入力測定にも無視できないノイズがある場合、入力PSDの分母にその成分が加わるため、独立な入力測定ノイズはH1のゲインを小さく見せます。

csd(y, x) に変えて分母を welch(x) のままにすると、推定値は共役になります。振幅だけ比較するとこの誤りを見逃します。純粋な \(d\) サンプルの遅延を入れたとき、位相が周波数に対して傾き \(-2\pi d/f_s\) で減少することを確認すると、引数の順序を検証できます。

Pythonで理論値と比較する

2048 Hzで生成した白色雑音を、遮断周波数160 Hzの4次Butterworthローパスに通します。出力に5サンプルの遅延と独立な雑音を加え、理論値にも同じ遅延の位相を含めます。ゲイン誤差と位相誤差は推定値を理論値で割って計算するので、理論位相が±180度をまたぐビンでも比較できます。

import numpy as np
from scipy import signal

fs = 2048
rng = np.random.default_rng(42)
sos = signal.butter(4, 160, fs=fs, output="sos")
delay = 5
x = rng.standard_normal(2**17)
z = signal.sosfilt(sos, x)
# np.roll would wrap the end of the record into its beginning.
y = np.r_[np.zeros(delay), z[:-delay]] + 0.03 * rng.standard_normal(x.size)
x, y = x[2048:], y[2048:]  # Discard the transient at the same indices.

nperseg = 2048
params = dict(
    fs=fs,
    window=signal.windows.hann(nperseg, sym=False),
    nperseg=nperseg,
    noverlap=nperseg // 2,
    detrend="constant",
    scaling="density",
)
f, pxx = signal.welch(x, **params)
_, pyy = signal.welch(y, **params)
_, pxy = signal.csd(x, y, **params)

excited = (f > 0) & (pxx >= 1e-3 * pxx.max())
h1 = np.full(pxy.shape, np.nan + 1j * np.nan)
np.divide(pxy, pxx, out=h1, where=excited)

denom = pxx * pyy
coh = np.full(f.shape, np.nan)
np.divide(abs(pxy) ** 2, denom, out=coh, where=denom > 0)
valid = excited & (coh >= 0.90)

_, ref = signal.sosfreqz(sos, worN=f, fs=fs)
ref *= np.exp(-2j * np.pi * f * delay / fs)

print("Hz   coherence   gain error (dB)   phase error (deg)")
for target in (64, 128, 160, 600):
    i = np.argmin(abs(f - target))
    if not valid[i]:
        print(f"{f[i]:3.0f}   {coh[i]:9.3f}   masked")
        continue
    ratio = h1[i] / ref[i]
    gain_error = 20 * np.log10(abs(ratio))
    phase_error = np.angle(ratio, deg=True)
    print(f"{f[i]:3.0f}   {coh[i]:9.3f}   {gain_error:+.3f}               {phase_error:+.3f}")

64 Hz、128 Hz、160 Hzでは理論値と近い結果を得られます。600 Hzではフィルタで入力由来の信号が強く減衰し、出力で雑音が支配的になるのでマスクされます。遅延の位相を理論値に含め忘れると、128 Hzの位相誤差は約 −112.5 度になります。

採用できる帯域を決める

  • 入力PSDで励振を確認する。 ゼロ除算を避けても、ほとんど励振されていないビンの応答を判断する根拠は得られません。例では入力PSDのピークから30 dB以内を採用候補にしています。実測では測定系のノイズ床や必要な励振帯域を基準に下限を決めます。
  • コヒーレンスと平均回数を確認する。 コヒーレンスの0.90はこの例のしきい値です。測定時間や目的に合わせて設定します。1区間だけでは、両PSDがゼロでないビンで分子と分母が数式上等しくなり、コヒーレンスは原理的に1です。十分な時間を記録し、複数区間で平均します。重なった区間どうしには相関があります。
  • 位相は連続した有効帯域ごとに扱う。 位相をアンラップして表示する場合は、マスクで分断された帯域ごとに処理します。np.unwrap(np.angle(h1[valid])) のように有効な点だけを詰めて並べると、測定できなかった帯域でも位相が連続すると仮定してしまいます。
  • 低周波やDCが必要なら測定方法を見直す。 この例では区間ごとに平均を引き、DCを除外しています。DCゲインの評価が必要なら、入力の定常レベルを変えたときの出力の変化を別途測れます。

入力と出力のサンプルレート、開始時刻、欠損箇所も確認します。固定の収録ずれは位相の傾きとして現れ、測定したい系の遅延と区別するには時刻校正が要ります。別クロックのずれで相対遅延が時間とともに変わると、区間平均でクロススペクトルが打ち消し合い、コヒーレンスも下がります。

よくある質問

scipy.signal.csdの引数は入力と出力のどちらが先ですか？

H1推定では入力を先にした csd(x, y) を入力PSDで割ります。出力を先にすると、同じ分母では位相の符号が反転します。

コヒーレンスが高ければゲインも正しいですか？

コヒーレンスはゲインの絶対精度を表す指標ではありません。たとえば出力側の校正係数が誤って一定倍になっていても、コヒーレンスの式ではその係数が相殺されます。

単一周波数の正弦波で全帯域の周波数応答を測れますか？

単一音では励振した周波数付近を測れます。全帯域を評価する場合、関心帯域をカバーする広帯域入力で十分な区間数を確保するか、周波数を変えながら各定常区間を評価します。
